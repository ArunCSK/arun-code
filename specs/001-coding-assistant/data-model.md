# Data Model & Key Entities: Arun-Code

## Entities

### NIMConfig
- **endpoint_url** (`str`): Base HTTP URL for NVIDIA NIM completions (Default: `https://integrate.api.nvidia.com/v1/chat/completions`).
- **api_key** (`str`): Secret key / Bearer token obtained from `NVIDIA_BEARER` or `NVIDIA_API_KEY`.
- **model_name** (`str`): Target NIM model string (e.g., `google/diffusiongemma-26b-a4b-it` or `meta/llama-3.1-70b-instruct`).
- **max_tokens** (`int`): Token limit per request (Default: 4096).
- **temperature** (`float`): Generation temperature parameter (Default: 0.7).

### ChatMessage
- **role** (`str`): `user`, `assistant`, or `system`.
- **content** (`str`): The message payload text.

### AgentResponse
- **content** (`str`): Human-friendly output text generated by the model or agent.
- **reasoning** (`str | None`): Reasoning output (if thinking mode is enabled).
- **tool_calls** (`list[dict] | None`): Record of tool actions executed during request.
- **error** (`str | None`): Friendly diagnostic message if NIM request fails.
